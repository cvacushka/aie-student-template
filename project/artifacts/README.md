# Артефакты Smart Campus AirGuard

Основные артефакты проекта лежат в отдельной папке `models/`, потому что сервису удобно загружать модель именно оттуда:

- `models/airguard_model.joblib` — сериализованный pipeline финальной модели;
- `models/experiments.csv` — таблица экспериментов;
- `models/metrics.json` — выбранная модель и test-метрики.

Папка `artifacts/` оставлена из исходного шаблона для дополнительных графиков, отчётов или небольших результатов, если они появятся позже.
