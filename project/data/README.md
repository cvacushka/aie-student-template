# Данные Smart Campus AirGuard

Проект использует синтетический обезличенный датасет: один объект описывает состояние аудитории в момент времени и целевой признак `co2_risk_next_30min`.

Целевой признак равен `1`, если модельная оценка CO2 через 30 минут превышает 1100 ppm или если сочетание CO2, температуры и влажности похоже на дискомфортную ситуацию.

Основной файл для демонстрации:

- `data/processed/airguard_dataset.csv` — синтетическая выборка на 6000 строк.

Сгенерировать данные заново:

```powershell
cd project
python -m airguard.data.generate_dataset --rows 6000
```

Данные не содержат персональных данных, реальных сенсорных выгрузок и конфиденциальной информации.
