# Ноутбуки Smart Campus AirGuard

В папке лежит `01_eda_and_experiments.ipynb`. Он показывает базовый сценарий анализа: генерацию синтетических данных, проверку распределений, сравнение классов и запуск обучения моделей.

Перед запуском ноутбука установите зависимости из `requirements.txt` и убедитесь, что пакет установлен из текущей папки `project`.
