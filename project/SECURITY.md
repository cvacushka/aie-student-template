# Security Notes

В проекте нет реальных паролей, токенов и закрытых данных.

Правила:

- реальные `.env` файлы не коммитятся;
- шаблон конфигурации лежит в `configs/.env.example`;
- данные синтетические и не содержат персональных данных;
- модельный API принимает только технические параметры аудитории;
- перед публикацией репозитория нужно проверить, что в истории git нет секретов и персональных данных.

Если проект будет развиваться до реальной интеграции с датчиками кампуса, нужно отдельно оформить доступы к BMS/HVAC, журналировать обращения к API и хранить секреты во внешнем secret storage.
