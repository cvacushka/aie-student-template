## 1. Dataset

- **Какой датасет выбран:** `S06-hw-dataset-01.csv`
- **Размер:** 12000 строк, 30 столбцов (28 признаков + id + target)
- **Целевая переменная:** `target` - бинарная классификация (0 или 1)
  - Класс 0: 67.66% (8119 примеров)
  - Класс 1: 32.34% (3881 примеров)
  - Распределение классов: см. график `artifacts/figures/target_distribution.png`
- **Признаки:**
  - **Числовые:** 24 признака (num01-num24), 1 признак tenure_months
  - **Категориальные:** 3 признака (cat_contract, cat_region, cat_payment)
  - Пропуски отсутствуют

## 2. Protocol

- **Разбиение:** train/test (75% / 25%), `random_state=42`, с `stratify=y`
  - Фиксированный `random_state` обеспечивает воспроизводимость эксперимента
  - Стратификация сохраняет одинаковое распределение классов в train и test
- **Подбор:** CV на train
  - **Метод:** GridSearchCV с 3-fold StratifiedKFold (shuffle=True, random_state=42) [оптимизировано для ускорения]
  - **Scoring:** ROC-AUC (площадь под ROC-кривой)
  - **Важно:** Подбор гиперпараметров выполняется только на train-выборке
- **Метрики:** 
  - **Accuracy** - доля правильных предсказаний (базовая метрика)
  - **F1-score** - гармоническое среднее precision и recall (баланс между precision и recall)
  - **ROC-AUC** - площадь под ROC-кривой (основная метрика для сравнения моделей в бинарной классификации)
  - Эти метрики уместны, так как задача - бинарная классификация с умеренным дисбалансом классов

## 6. Conclusion

1. **Ансамблевые методы превосходят базовые:**
   - RandomForest показал лучший результат (ROC-AUC: 0.9679), превосходя DecisionTree (ROC-AUC: 0.9098) и AdaBoostClassifier (ROC-AUC: 0.9070) благодаря снижению variance через независимое обучение моделей на bootstrap-выборках.

2. **Контроль переобучения критически важен:**
   - Использование регуляризации (max_depth, min_samples_leaf, ccp_alpha) позволяет контролировать сложность деревьев и избежать переобучения.
   - Без контроля сложности дерево решений легко переобучается на обучающей выборке.

3. **Честный ML-протокол обеспечивает надежность:**
   - Фиксированный train/test split с random_state обеспечивает воспроизводимость эксперимента.
   - CV используется только для подбора гиперпараметров на train, test используется один раз для финальной оценки.
   - Такой подход исключает "подглядывание" в test при подборе параметров.

4. **Bagging vs Boosting - разные подходы к ансамблю:**
   - Bagging (RandomForest) снижает variance через независимое обучение моделей на bootstrap-выборках и показал лучший результат в данном эксперименте (ROC-AUC: 0.9679).
   - Boosting (AdaBoost) последовательно улучшает модель, фокусируясь на сложных примерах, и показал результат ROC-AUC: 0.9070.

5. **Интерпретируемость моделей важна:**
   - Permutation importance позволяет понять, какие признаки важны для модели.
   - Это важно не только для понимания работы модели, но и для domain-экспертов, которые могут использовать эти знания в практике.

6. **Выбор метрик зависит от задачи:**
   - ROC-AUC подходит для бинарной классификации, когда важна работа модели на разных порогах.
   - F1-score полезен, когда важен баланс между precision и recall.
   - Accuracy может быть обманчивой при дисбалансе классов.
