# Конфиги Smart Campus AirGuard

В проекте используются:

- `configs/model_config.json` — описание целевого признака, горизонта прогноза, порога риска и правила выбора модели;
- `configs/.env.example` — пример переменных окружения для локального запуска без реальных секретов.

Настройки путей также читаются из переменных окружения в `src/airguard/config.py`.
